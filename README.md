# AII 公链文档资料包

> **AII = AI 原生公链（AI-Native L1）**
> 首条把 **MCP Server + CLI（`aii`）** 内建到协议层的公链——Claude Desktop / Claude Code / Cursor / Cline 等 AI 智能体**零 SDK、零样板**即可操作链。
>
> AII 是完全去中心化的开源协议——**无公司、无基金会、无机构、无团队预挖、无投资人、无私募公募、无 DAO 治理、无链上投票**。
> 灵感来源于 MOAC 的分层多链架构，但完全 Rust 重新实现，主链共识为纯 PoS BFT。代币总量 **2100 亿 AII**。
>
> 状态：v0.6（AI 原生定位 + 2100 亿总量）

## 文档间一致性基线

所有文档共享如下事实集（详见 00 术语表与 02 项目章程）：

| 维度 | 设定 |
|---|---|
| **项目性质** | 完全去中心化的开源协议（**无任何法律实体**）|
| **总体架构** | 分层多链：主链 + 多子链 |
| **主链共识** | **纯 PoS BFT**（VRF 提议者 + ⅔ stake PRE-COMMIT，单区块即时最终性） |
| **子链共识** | 可插拔：PoS / PBFT / DPoS / Custom |
| **节点角色** | V 节点 + SCS 节点 + 5 个其他 Tier（7 Tier 模型） |
| **主链 VM** | EVM 完全兼容（基于 revm） |
| **子链 VM** | EVM + WASM 双轨 |
| **跨链** | 内部协议 + HTLC + 多签桥 + IBC + （后期）XCM |
| **治理** | **完全无治理**：协议常量化 + Bitcoin 式 rough consensus 升级 |
| **法律实体** | **无**（开源协议，类 Bitcoin / Linux）|
| **开发语言** | **Rust 全栈** |
| **多端覆盖** | PC（Win/Mac/Linux Tauri）+ 移动（iOS/Android 原生）+ 浏览器扩展 |
| **AI 集成** | 协议级 CLI（`aii`）+ MCP Server |
| **代币模型** | **预约启动**：10K 名额 × 1,000,000 AII 创世预分配 + 95% PoS 出块释放 |
| **代币总量** | **210,000,000,000 AII**（原生大供应模型；协议级硬约束）|
| **通缩机制** | EIP-1559 base_fee 100% 销毁 |
| **应急响应** | SECRC 7 人 5/7 多签（仅紧急热补丁与 5 亿 AII (500M) 小额运营，无任何治理权）|

修改任一基线项时，请同步更新所有相关文档。
