# AII 公链开发前置文档资料包

> 本目录为 AII 公链项目的全套中文文档。AII 是一个**完全去中心化的开源公链协议**——
> 无公司、无基金会、无机构、无团队预挖、无投资人、无私募公募、无中心化主体。
> 灵感来源于 MOAC 的分层多链架构，但完全 Rust 重新实现，主链共识为纯 PoS BFT。
>
> 状态：v0.4 公平启动版

## 文档间一致性基线

所有文档共享如下事实集（详见 `00_术语表.md` 与 `01_技术白皮书.md` §10）：

| 维度 | 设定 |
|---|---|
| 总体架构 | 分层多链：主链 + 多子链 |
| 主链共识 | **纯 PoS BFT**（V 节点 + VRF 提议者 + ⅔ stake PRE-COMMIT，单区块即时最终性） |
| 子链共识 | 可插拔：PoS / PBFT / DPoS / Custom |
| 节点角色 | V 节点（底层）+ SCS 节点（子链） + 5 个其他 Tier |
| 主链 VM | EVM 完全兼容（基于 revm） |
| 子链 VM | EVM + WASM 双轨 |
| 跨链 | 内部协议 + HTLC + 多签桥 + IBC + (后期)XCM |
| **治理** | **无任何治理**（Bitcoin 式：协议常量 + rough consensus 升级） |
| **法律实体** | **无**（开源协议，类 Bitcoin / Linux） |
| 开发语言 | **Rust 全栈** |
| 节点分级 | 7 Tier（T1 V节点 → T7 移动钱包），客户端自动识别 |
| 多端覆盖 | PC（Win/Mac/Linux，Tauri）+ 移动（iOS/Android，原生）+ 浏览器扩展 |
| AI 集成 | 协议级 CLI（`aii`）+ MCP Server |
| **代币模型** | **预约启动**：10K 名额 × 100 AII 创世预分配 + 95% PoS 出块释放（无团队/投资人）|
| **代币总量** | **21,000,000 AII**（沿用 2100 万哲学），每 4 年减半 |
| 通缩机制 | EIP-1559 base_fee 100% 销毁 |

修改任一基线项时，请同步更新所有相关文档。
